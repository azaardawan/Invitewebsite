# Music

Put songs here (mp3, m4a, aac, wav, ogg or flac) and choose one per render with
`"music": "<file name>"` in the request. Every video already has the sewing-machine sound;
the music is mixed well under it (see `../audio_mix.py`), so the stitching is always heard,
however loud the song was mastered. Only add music you have the rights to use.
